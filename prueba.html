Generador de Links de Campaña

Genera rutas Web, Deeplinks App y links finales de campaña para destinos WebView y Nativos.

1Destino del producto

Selecciona un producto existente o genera las rutas desde cero. Para WebView normalmente basta con una sola ruta; para Nativo necesitas una ruta Web/fallback y un destino propio de App.

Al elegir un producto, el tipo de destino y las rutas se detectan automáticamente.
