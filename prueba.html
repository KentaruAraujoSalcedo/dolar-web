Generador de Links de Campaña

Genera enlaces listos para campañas digitales sin tener que construir parámetros o codificar deeplinks manualmente.

1 Selecciona el producto

Busca el producto que utilizará la campaña. Las rutas Web y App se completarán automáticamente.

Puede modificarse manualmente si fuera necesario.
Deeplink que abrirá la experiencia dentro del app.

2 Datos de campaña

Selecciona un valor recomendado o escribe uno diferente si la campaña requiere una nomenclatura especial.

Plataforma o fuente que genera el tráfico.
Tipo de tráfico o medio de campaña.
Nombre de la campaña. Respeta la nomenclatura definida por Marketing.

Este producto utiliza WebView. Completa también los parámetros internos de navegación.

3 Link generado

Este es el enlace final que debe utilizarse en la plataforma de campaña.

Completa los datos anteriores y presiona Generar link de campaña.
